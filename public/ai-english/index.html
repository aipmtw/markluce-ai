AI Prompt Vocabulary

40 個 AI 時代最常用的英文 Prompt 核心字
附完整例句 + AI 語音（Azure Neural TTS），專為 dev / PM / AI 工作者設計

1–5

基本操作動詞

佔 50% prompt usage

01 generate 生成 /ˈdʒɛnəˌreɪt/
"Generate a list of 10 startup ideas based on current AI trends."
「根據目前的 AI 趨勢，生成 10 個新創點子。」
0:00 0:00
02 create 建立 /kriˈeɪt/
"Create a REST API endpoint that returns user profile data in JSON."
「建立一個回傳使用者資料的 REST API 端點，格式為 JSON。」
0:00 0:00
03 write 撰寫 /raɪt/
"Write a unit test for the login function using Jest."
「用 Jest 撰寫登入功能的單元測試。」
0:00 0:00
04 explain 解釋 /ɪkˈspleɪn/
"Explain how JavaScript closures work with a simple example."
「用簡單的例子解釋 JavaScript 閉包的運作方式。」
0:00 0:00
05 summarize 摘要 /ˈsʌməˌraɪz/
"Summarize this meeting transcript into three key action items."
「將這份會議記錄摘要成三個重點行動項目。」
0:00 0:00
6–10

調整 & 優化

improve = 通用改善  |  refine = 專業微調  |  optimize = 技術最佳化
06 improve 改善 /ɪmˈpruːv/
"Improve this error message to be more user-friendly and actionable."
「改善這個錯誤訊息，使其更友善且可操作。」
0:00 0:00
07 refine 精煉 /rɪˈfaɪn/
"Refine the database query to reduce response time below 200 milliseconds."
「精煉這個資料庫查詢，將回應時間降到 200 毫秒以下。」
0:00 0:00
08 optimize 最佳化 /ˈɑːptɪˌmaɪz/
"Optimize this React component to prevent unnecessary re-renders."
「最佳化這個 React 元件，避免不必要的重新渲染。」
0:00 0:00
09 rewrite 重寫 /ˌriːˈraɪt/
"Rewrite this callback-based code using async/await syntax."
「用 async/await 語法重寫這段 callback 程式碼。」
0:00 0:00
10 simplify 簡化 /ˈsɪmplɪˌfaɪ/
"Simplify this function so a junior developer can understand it."
「簡化這個函式，讓初階開發者也能理解。」
0:00 0:00

0:00 0:00
12 convert 轉換 /kənˈvɜːrt/

13 list 列出 /lɪst/

「列出這個付款流程所有可能的邊界情境。」
0:00 0:00
14 organize 整理結構 /ˈɔːrɡəˌnaɪz/
"Organize these API routes into logical groups with clear naming conventions."
「將這些 API 路由整理成邏輯群組，使用清楚的命名慣例。」
0:00 0:00

"Structure this project with separate folders for components, hooks, and utilities."
「用元件、hooks 和工具函式的獨立資料夾來結構化這個專案。」
0:00 0:00

"Suggest three ways to improve the onboarding experience for new users."
「建議三種改善新用戶引導體驗的方法。」
0:00 0:00

「模擬一段客戶與客服人員之間關於退款的對話。」

21–25

情境 & 判斷

描述場景、做出區分

21 scenario 情境 /sɪˈnɛrioʊ/

「描述一個在高負載下，這個驗證流程可能失敗的情境。」

「在這個情境下，區分伺服器端渲染和客戶端渲染的差異。」

23 differentiate 區別 /ˌdɪfəˈrɛnʃiˌeɪt/

「在微服務架構中，區別 REST API 和 GraphQL 的使用場景。」

「校準模型的 temperature 設定，以平衡創意與準確度。」

技術 & 學術詞彙

寫文件、讀論文必備

phenomenon（單數）vs phenomena（複數）— 學術寫作常見錯誤，AI prompt 裡也要注意

"Explain the mechanism behind token-based authentication in modern web apps."
「解釋現代 Web 應用中，基於 Token 驗證的機制。」
0:00 0:00
32 anonymous 匿名的 /əˈnɑːnɪməs/
"Allow anonymous users to browse the catalog but require login before checkout."
「允許匿名使用者瀏覽目錄，但結帳前需要登入。」
0:00 0:00
33 phenomenon 現象（單數） /fɪˈnɑːmɪˌnɑːn/
"This hallucination phenomenon is a known limitation of large language models."
「這種幻覺現象是大型語言模型的已知限制。」
0:00 0:00
34 phenomena 現象（複數） /fɪˈnɑːmɪnə/
"These phenomena occur simultaneously when the system is under heavy concurrent load."
「當系統承受大量並發負載時，這些現象會同時發生。」
0:00 0:00

「同時執行測試和程式碼檢查，加速 CI 流程。」

36 privilege 權限 /ˈprɪvəlɪdʒ/
"Grant the service account read-only privilege to the production database."
「授予服務帳號正式資料庫的唯讀權限。」

37 authenticate 驗證身份 /ɔːˈθɛntɪˌkeɪt/
"Authenticate the user via LINE Login before granting access to premium content."
「透過 LINE Login 驗證使用者身份，再授權存取付費內容。」

38 configure 設定 /kənˈfɪɡjər/
"Configure the environment variables for both staging and production deployments."
「為測試環境和正式環境的部署設定環境變數。」
0:00 0:00
39 archive 封存 /ˈɑːrkaɪv/
"Archive last month's subscription data before running the cleanup job."
「在執行清理作業前，先封存上個月的訂閱資料。」
0:00 0:00
40 achieve 達成 /əˈtʃiːv/
"What steps do we need to achieve 99.9% uptime for this service?"
「我們需要哪些步驟才能達成這個服務 99.9% 的正常運行時間？」
0:00 0:00
archive vs achieve — 發音相近但意思完全不同！archive = 封存（/ˈɑːrkaɪv/），achieve = 達成（/əˈtʃiːv/）

Bonus: 高階常用句型

控制輸出

"in markdown format" — 用 Markdown 格式
"step-by-step" — 一步步來
"in table format" — 用表格呈現

限制範圍

"based on best practices" — 根據最佳實踐
"for production use" — 適用於正式環境
"for beginners / advanced users" — 面向初學者 / 進階用戶

精準控制（高手關鍵）

"be concise but complete" — 精簡但完整
"avoid generic answers" — 避免泛泛之談
"focus on practical implementation" — 專注實作
