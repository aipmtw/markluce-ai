💡 關鍵學習心得

  1. 轉錄 ≠ 正確 — faster-whisper 在中文人名上準確率有限（蔡政霖→蔡哲銘、黃仁勳→黃榮勳、藤子不二雄→薩琼周艾夢）
  2. PDF 講義是 Ground Truth — 所有人名、數字、專有名詞必須以講義為準
  3. Agenda 比 PDF 標題更可信 — PDF 標題混用了兩堂課的內容，agenda 上的正式課名才是官方的分段
  4. 備份錄音的價值 — 兩台裝置錄同一場，主錄音轉錯時可以交叉核對
  5. 三層校對：語音 → 講義 → 議程 — 每多一層來源，正確率就高一層
