Gen AI 是什麼？用一張圖講完

本質：把不同輸入（文字/影像/聲音/影片）經過「模型 Function」轉換成另一種輸出。

「工程上，模型就是一個 function。你丟文字進去，它給你影像；丟影像進去，它給你文字。從左邊到右邊可以，從右邊回推到左邊也可以 — 這就是逆向工程。」

逆向工程的威力

  • 過去：人工寫程式 / 寫指令 → 產生結果
  • 現在：把已經做好的成品丟給 AI，讓它反推「這是怎麼做出來的」→ 得到指令/程式碼
  • 把指令包成 Skill → 以後同類任務只要餵新資料，就能一鍵產出

經典梗：藤子·F·不二雄 47 年前的 AI 構想 — 高品質資料 → 模型訓練／微調 → 用 AI Prompt → 建立 Skill，這個流程跟當代 AI pipeline 一模一樣。

Skill：AI 的「技能卡」

Skill = 把某個工作流程的「隱性知識」寫成 AI 看得懂的操作指令。

  • 場景：教新進同仁「資料在哪、怎麼抓、怎麼處理、怎麼輸出」 → 這整套流程就是一張 Skill
  • 流程：
    1. 跟 AI 一步步做完一次任務
    2. 請 AI「把剛剛做的事打包成 Skill」
    3. 再跑一次確認無誤
    4. 把 Skill 分享給 PM / 其他同仁使用
「公司內部的隱性知識本來都散在同仁的 Word、Excel 裡，同事離職就消失。用 Skill 把流程寫下來，它就變成公司資產。」

實戰案例

A. 行銷提案報告：16 小時 → 10 分鐘

以前同仁做一份行銷提案需 ~16 小時。寫好 Skill 後，丟 Excel 資料 + 指令，10 分鐘產出草稿，再半小時微調 = 2 天壓縮到 30 分鐘。

B. Supermicro 演講：60 頁投影片 + 演講稿

用 Claude Opus Live Coding 分析 Supermicro 公開的 Tier-1 機器調校程式，再把 IT 主管給的演講方向餵進去 → 產出 60 頁簡報 + 演講稿。二三十分鐘就完成。

C. 從媒體操作手冊反推出系統 PRD

同仁把一本媒體操作手冊丟給 AI → 2-3 小時逆向工程產出 PRD → 做出整套系統雛型（「結果做太大了，不是本來預期的規模」）。

黃仁勳的願景：7.5 萬員工 + 750 萬 Agent

  • Nvidia 黃仁勳（Jensen Huang）宣示：未來 NVIDIA 將是 7.5 萬員工 + 750 萬 AI 代理（AI Assistant / Agents）的公司。
  • AI 代理遍布公司每個部門（行銷、法律、工程、供應鏈）— 自主處理任務來極大化生產力。
  • 作法：盤點公司內每一個職位的產出步驟 → 為每一個流程建一個 agent。
  • 電通正在做的事：每個產出部的每個步驟 → 確認工具鏈 → 建 agent。
「以後員工入職第一天，公司會配一個 agent 給你。這個 agent 跟你一起工作，直到你離職 — 你的隱性知識就留存在公司裡，變成公司資產。」

本課重點

  • 1. Gen AI 本質是一個 function：左邊輸入 → 模型 → 右邊輸出。重點是兩邊都可以當起點。
  • 2. 逆向工程是生產力核心：從已有成品反推指令，包成 Skill → 下次只需餵資料。
  • 3. Skill = 企業隱性知識資產化：個人工作流變成公司資產，員工離職也不消失。
  • 4. AI Agent 是下一步：黃仁勳的「7.5 萬人 + 750 萬 agent」是主流企業的未來。
  • 5. 選對引擎：程式任務選 Claude，第一性原理分析選 Grok，中文語氣選 Qwen，企業導入必加 Guardrail。
  • 6. Claude $200 方案：相當於 $4000 額度，3-4 人共用最划算。
