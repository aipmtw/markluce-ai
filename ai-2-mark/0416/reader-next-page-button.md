# Reader — Next Page Button on Content Pages

## Feature

Add a visible "Next Page" button on each content page, similar to the cover's "開始閱讀 Start Reading ▶" button. Currently users can only advance by swiping, clicking edges, or arrow keys — all invisible affordances. A visible button improves discoverability, especially for young readers and parents.

## Design

- Positioned at the bottom of the page text area
- Bilingual label respecting language selector: `下一頁 / Next Page ▶`
- On the last content page: `故事結束 / The End ▶` → navigates to universal end screen
- Style: subtle, not as prominent as the cover Start button — a text link or small pill button
- Does NOT appear on cover (has Start Reading) or end screen (has 回到書架)
